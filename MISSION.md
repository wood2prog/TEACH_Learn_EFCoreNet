# Mission: Entity Framework Core

## Why
I want to be able to work on .NET projects that use EF Core for data access. I have theoretical knowledge from tutorials but haven't built anything real yet. I need practical, hands-on skills so I can contribute to real projects with confidence.

## Success looks like
- Scaffold an EF Core project from scratch without referencing a guide
- Model a domain with multiple related entities (one-to-many, many-to-many)
- Write performant LINQ queries using eager loading, filtering, and projection
- Use migrations to evolve a database schema in a team setting
- Debug and fix common EF Core issues (N+1, tracking, concurrency)

## Constraints
- Sessions should be ~30 minutes each
- Learning must be hands-on — code-first with a real .NET project
- Prefer SQLite for local development (no server setup needed)

## Out of scope
- Deep SQL/database theory
- Other .NET data access technologies (Dapper, ADO.NET)
- Production deployment of databases (Docker, cloud provisioning)
