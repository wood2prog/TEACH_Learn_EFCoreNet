# EF Core Resources

## Knowledge

- [Official EF Core Documentation — Microsoft Learn](https://learn.microsoft.com/en-us/ef/core/)
  The canonical source. Covers every feature, every provider, every version. Use for: reference, API details, migration guidance, and "how do I…" lookups.

- [Getting Started Tutorial — EF Core Console App with SQLite](https://learn.microsoft.com/en-us/ef/core/get-started/overview/first-app)
  Official walkthrough for building a first app. Use for: initial scaffolding and understanding the end-to-end flow.

- [Book: _Entity Framework Core in Action, Second Edition_ — Jon P Smith (Manning, 2021)](https://www.manning.com/books/entity-framework-core-in-action-second-edition)
  Practical, production-focused. Covers patterns, performance, testing, and security. Use for: deep understanding of real-world EF Core usage.

- [Book: _Practical Entity Framework Core 10_ — Brian Gorman (Apress, 2026)](https://www.oreilly.com/library/view/practical-entity-framework/9798868821233/)
  Up-to-date for EF Core 10 with code-first focus. Use for: latest features and enterprise patterns.

- [ASP.NET Core MVC with EF Core — Microsoft Learn Tutorial Series](https://learn.microsoft.com/en-us/aspnet/core/data/ef-mvc/?view=aspnetcore-8.0)
  Multi-part tutorial building the Contoso University sample app. Use for: understanding EF Core in a web application context.

## Wisdom (Communities)

- [Stack Overflow: entity-framework-core tag](https://stackoverflow.com/questions/tagged/entity-framework-core)
  ~23,000 questions. Use for: troubleshooting specific errors, seeing patterns in what goes wrong in production.

- [Microsoft Q&A: EF Core](https://learn.microsoft.com/en-us/answers/tags/30/ef-core)
  Official Microsoft Q&A forum. Use for: getting answers from Microsoft engineers and MVPs.

- [r/dotnet on Reddit](https://reddit.com/r/dotnet)
  Active .NET community. Use for: discussions on best practices, library recommendations, ecosystem news.
